# Aloha Window Bros — Site Map

## Tech Stack
- **Framework**: Astro 6 (static output)
- **Styling**: Global CSS (Inter + Playfair Display fonts), blue→purple wave theme from truck branding
- **Content**: Astro Content Collections (markdown with frontmatter)
- **Tracking**: GA4 (G-MRSP8D9CQG) with custom conversion events + Meta Pixel (2085643305314161) — **gated behind Consent Mode v2 cookie banner**; default state is denied. See `src/components/CookieBanner.astro` + consent block at top of `Base.astro`.
- **Deploy**: Docker nginx container via blrb-connect, GitHub Actions auto-deploy

## Automated publishing: Outrank webhook (live 2026-07-31)

**Blog posts can now arrive on this site without a human touching the repo.** Outrank (the
backlink-exchange / AI article platform) POSTs finished articles to a webhook; a service on the VPS
converts each one to a `src/content/blog/*.md` file, commits it to `main`, and pushes. The normal
GitHub Actions runner deploys it. **If you find a blog post you did not write, this is why**. Check
`git log` for commits authored by `Aloha Publisher <publisher@alohawindowbros.com>`.

| Piece | Where |
|---|---|
| Endpoint | `https://alohawindowbros.com/api/outrank/webhook` (non-www only; www 301s and a POST would not survive it) |
| Service | `aloha-publish.service` on the VPS, code at `/root/services/aloha-publish/server.mjs`, binds 127.0.0.1 + 172.18.0.1 on :8790 (never public) |
| Config | `/root/services/aloha-publish/aloha-publish.env` (600, holds the bearer token) |
| Its own repo clone | `/root/services/aloha-publish/repo`, **separate from `/root/sites/aloha2`**, pushes via deploy key `aloha_publish` (`Host github-aloha`) |
| Log | `/root/services/aloha-publish/log/publish.log` + `journalctl -u aloha-publish` |
| Slack | posts to `#aloha-seo` on every successful publish |

**To stop it publishing:** set `PUBLISH_MODE=hold` in the env file and
`systemctl restart aloha-publish`. Articles then queue in `/root/services/aloha-publish/spool/` and
nothing is pushed. `systemctl stop aloha-publish` makes the endpoint 502 instead, which Outrank will
treat as a delivery failure, so prefer `hold`. To revoke Outrank entirely, rotate the token in the env
file (and remove the deploy key from the GitHub repo settings to cut push access).

**What the service does to incoming content**, because there is no human review step:
- **Sweeps em/en dashes** (site hard rule). Ranges become "to", a title break becomes a colon, and
  a prose break becomes a comma. This is mechanical, so it can produce a comma splice where a period
  or colon was right. The log emits `em dashes swept, worth a human read` with a count, and those
  posts are worth re-reading. See the em-dash entry in Gotchas below.
- Strips `<script>`, `<style>`, `<iframe>`, `<form>`, and inline `on*=` handlers.
- Strips a leading H1 (the `[slug].astro` template renders the title itself, so leaving it would
  double the H1).
- Downloads `image_url` into `public/img/blog/<slug>.<ext>` and sets `heroImage` to the local path,
  rather than hotlinking Outrank's CDN. If the download fails, `heroImage` is simply omitted.
- Batches a burst of articles into one commit (20s debounce) so N articles are **one** deploy, not N
  racing ones.

**Not enforced, and worth knowing:** the service does not cap outbound links or check what Outrank
links to. Given this domain's backlink history (see `disavow.txt`, ~93% spam disavowed 2026-06-01),
the outbound profile of auto-published posts is worth auditing periodically.
