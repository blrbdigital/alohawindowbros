## SEO
- Per-page title, description, canonical, Open Graph
- Titles kept <60 chars (page <title> drops brand suffix; brand stays in OG, JSON-LD, header logo)
- JSON-LD: LocalBusiness (home + cities), Article + BreadcrumbList (blog), Service + BreadcrumbList (services), FAQPage (city pages)
- **Image metadata**: `src/lib/seo.ts` builds schema.org `ImageObject` (url, contentUrl, caption, width/height, creditText, creator, copyrightNotice). `businessImages` (3 representative photos) feeds the `image` property on every LocalBusiness node; blog Article `image` uses `imageObject()` with `heroImageAlt` as caption. Fixes GSC "no image metadata" — images were previously bare URL strings. Static image dimensions are hardcoded from `sips`; update them in seo.ts if those files change.
- Sitemap at /sitemap-index.xml (legacy `/sitemap.xml` 301s to current index)
- `/llms.txt` — AI-search index file pointing at services, cities, and guides
- 301 redirects from old WordPress URLs (blog, service, city .html, /index, /service, /schedule)
- 301 redirect for www → non-www (Host: www.alohawindowbros.com server block)
- 410 Gone for wp-admin, wp-login, wp-content, wp-includes, wp-json, xmlrpc, wp-*.php
- Nginx gzip enabled (text/css, JS, JSON, XML, SVG) — fixes "uncompressed JS/CSS" Semrush warning
- HSTS header (max-age=31536000, includeSubDomains)
